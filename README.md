# Paradise Nursery

Paradise Nursery is a responsive online plant shop created as a college project. Visitors can browse houseplants by category, add plants to a shopping cart, change item quantities, remove products, and review the order subtotal.

## Features

- Landing page with the Paradise Nursery name, plant background image, and a Get Started button.
- Company information in the About Us section.
- Product catalog with plant photos, descriptions, prices, and add-to-cart controls.
- Shopping cart with quantity updates, item removal, item count, and a calculated total.
- Responsive layout for desktop and mobile screens.

## Project files

- `src/App.jsx` — Paradise Nursery landing page.
- `src/App.css` — Landing page background image and styles.
- `src/AboutUs.jsx` — Company details.
- `src/CartSlice.jsx` — `addItem`, `removeItem`, and `updateQuantity` cart reducers.
- `src/ProductList.jsx` — Plant catalog and category listing.
- `src/CartItem.jsx` — Shopping cart page component.

## Run locally

Install dependencies with `bun install` or `npm install`, then start the development server with `bun run dev` or `npm run dev`.
